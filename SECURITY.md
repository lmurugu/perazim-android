# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of the Perazim Android Application:

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

The Perazim Church engineering and ministerial team take the security and privacy of our congregation, donors, and users seriously.

If you discover a potential security vulnerability in this application (including financial handling, prayer wall integrity, or network communications), please notify us privately:

- **Email**: `security@perazimchurch.org` or `bishop@perazimchurch.org`
- **Subject**: `[SECURITY VULNERABILITY] Perazim Android App`

Please include:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept code to reproduce the issue.
3. Affected device configurations or Android OS versions.

### What to Expect
- **Acknowledgment**: Within 48 hours of receipt.
- **Triage & Evaluation**: We will evaluate the impact and coordinate on a fix.
- **Responsible Disclosure**: We ask that you give us adequate time to release a patch before disclosing details publicly.

## Credential & Giving Integrity Verification

- **Official M-Pesa Paybill**: The official church Paybill number hardcoded and used in all distributions is `4069983` (Account Name: Perazim Mission Church). Any variant claiming to represent the church with another business number should be reported immediately.
- **No Secret Storage**: This open-source repository does not and will never contain private signing keys, production keystores, or financial API secrets.
