# Bible audio already on your phone

1. Open **Sermons → Bible audio on this phone**.
2. Tap **Add Bible audio from this phone**, select the Bible book, then choose
   its existing audio file with the phone's file picker.
3. Use the saved entry to play, pause, seek, or stop. Selections remain saved
   after closing the screen. Playback stops when the screen is backgrounded.

The library keeps a reference and permission to the selected file. If a legacy
picker cannot retain access, the app keeps a private copy of that selected file
(up to 25 MB). It does not upload, redistribute, or bundle your recording.
Removing an entry does not delete the original audio. Moving or deleting an
original referenced file may require selecting it again.

The app uses the system file picker where available. On phones without an audio
picker, it requests the Android audio/media permission and offers matching small
recordings from the media library. It does not request all-files management.
File availability depends on the phone's file provider and permission settings.
The library is local to this app installation on this device.
