# Cookie Policy

Status: Draft (not approved). Version 0.1. Last reviewed: 2026-11-18.

The Perazim Android app does not set cookies. It does not use web storage, tracking pixels, advertising identifiers, or third-party analytics. Session data is stored in the device's encrypted store and is used only to keep you signed in.

If the church publishes a website that uses cookies or similar technologies, this policy will be replaced and a consent banner will be added before that website goes live. The decision is recorded in `docs/adr/0001-no-cookie-banner.md`.
